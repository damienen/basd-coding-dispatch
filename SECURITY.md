# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting a Vulnerability

Open a security advisory or contact the maintainers through the repository security channel. Do not post exploit details in a public issue if the report includes a working exploit or sensitive material.

## Repository Safety Rules

- Never commit credentials, private paths, private chat identifiers, or private client/project data.
- Keep examples generic.
- Do not add native plugin metadata until the install path is validated.
- The npm scaffolder must refuse to overwrite files unless `--force` is used.
